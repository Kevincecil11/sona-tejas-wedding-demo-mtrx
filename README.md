# Sona & Tejas · Wedding invitation (concept)

A single-page wedding invitation for Sona & Tejas, Mahabalipuram, 25 to 27 February 2027.
Concept by MTRX™ Digital.

## Before hosting: add the assets folder
Upload the `assets` folder (fonts and images) to the root of this repo: **Add file → Upload files**, then drag the whole `assets` folder in and commit to `main`.

## Host on GitHub Pages
1. Settings → Pages → Build and deployment → Source: **Deploy from a branch**
2. Branch: **main**, folder: **/ (root)** → Save
3. The site goes live at `https://kevincecil11.github.io/sona-tejas-wedding/` in a minute or two.

## Personal guest links
Add `?g=Name` to the link, for example `.../sona-tejas-wedding/?g=Priya`.
The opening and the greeting will show the guest's name.

## Files
- `index.html`: the whole page (styles and scripts inline)
- `assets/fonts`: Gloock, Carattere, Gotu, Cormorant Infant (subset, woff2)
- `assets/images`: paintings and outfit moodboards (webp)

The RSVP buttons are a preview only and do not store responses.
